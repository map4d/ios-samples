# Samples for Map4D iOS SDKs

## Run a sample

1. With CocoaPods installed, run `pod install` from the sample directory that contains the `Podfile`.

2. In the app target's `Info.plist`, replace the placeholder value for `Map4dMapAccessKey` with your own Map4D access key.

3. Open the `.xcworkspace` generated by CocoaPods in Xcode, select the sample's scheme, and run the app.
