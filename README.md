# Samples for Map4D iOS SDKs

## Run the simplemap sample

1. Open `simplemap/simplemap.xcodeproj` in Xcode. Xcode resolves and downloads `Map4dMap` through Swift Package Manager.

2. In `simplemap/simplemap/Info.plist`, set `Map4dMapAccessKey` to your own Map4D access key.

3. Select the `simplemap` scheme and an iOS simulator or device, then run the app.
